# Getting started

1. Install Node.js 22 or newer.
2. Install Triss with `npm install -g triss-coworker` or use the standalone
   installer documented in the README.
3. Run `triss config wizard`.
4. Verify the installation with `triss --version`, `triss --help`, and
   `triss status`.
5. Try `triss ask --paths README.md --question "Summarize this project"`.

Selected repository content is sent to the configured model provider. Read
[data-flows.md](data-flows.md) before using confidential repositories.

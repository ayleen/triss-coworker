# Support

- Use GitHub Issues for reproducible defects, provider compatibility reports,
  and scoped feature requests.
- Use GitHub Discussions for setup questions and general usage help.
- Use GitHub Security Advisories for vulnerabilities; do not post credentials
  or exploit details in a public issue.

Support is best-effort and has no guaranteed response time. The current minor
release line receives fixes. Older versions may be asked to reproduce on the
latest release before investigation. Deprecated behavior and removal windows
are tracked in [docs/deprecations.md](docs/deprecations.md).

For an emergency release, a maintainer opens a private security advisory or a
restricted incident, prepares the smallest fix, runs the normal release gates,
publishes through the protected OIDC workflow, and documents follow-up work.

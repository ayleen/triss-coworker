# IBM Plex assets

These WOFF2 files are committed, build-time site assets. They are sourced
from the IBM Plex repository's `packages/plex-sans` and `packages/plex-mono`
complete WOFF2 directories at upstream commit
`bf260093582f04622aacc1e9f9ca604d7ccd0c42` and are served from `/fonts/`; the
build performs no font download and the browser makes no third-party font
request.

The files are distributed under the SIL Open Font License. See `OFL.txt`.
